# Батарея Bluetooth

Небольшое приложение для области уведомлений Windows. Оно показывает заряд сопряжённых Bluetooth-устройств, которые сами сообщают его системе.

Панель открывается наведением или щелчком по значку. В строке устройства — имя, процент и состояние: «Заряжается», «Не заряжается» или «Состояние неизвестно». Процент берётся только из чтения системы. Если чтения нет, строка не появляется и число не подставляется.

Если ни одно устройство не сообщило заряд, панель показывает: «Нет данных о заряде».

## Требования

- Windows 10 версии 2004 (сборка 19041) или Windows 11
- [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0)
- Для обычного запуска ещё нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- Bluetooth-устройство уже сопряжено в Windows и умеет сообщать заряд

## Сборка и запуск на Windows

Команды из каталога `battery-tray`:

```bash
dotnet test
dotnet run --project src/BatteryTray.App/BatteryTray.App.csproj -c Release
```

Готовый файл без лишней публикации:

`src/BatteryTray.App/bin/Release/net8.0-windows10.0.19041.0/BatteryTray.exe`

Сборка под конкретную систему, рядом с `appsettings.json`:

```bash
dotnet publish src/BatteryTray.App/BatteryTray.App.csproj -c Release -r win-x64 --self-contained false -o artifacts/win-x64
```

Запуск: `artifacts\win-x64\BatteryTray.exe`. Для `win-arm64` замените идентификатор в `-r`.

Пока публикация не самодостаточная, на машине должен стоять .NET 8 Desktop Runtime. Самодостаточный вариант: та же команда с `--self-contained true`.

Значок один на сессию. Второй запуск ничего не открывает. Правый щелчок по значку: «Обновить» и «Выход». Левый щелчок закрепляет панель; повторный щелчок, щелчок снаружи или Esc её закрывает. Панель, открытая наведением, закрывается, когда курсор уходит. Список обновляется каждые 30 секунд и в момент открытия. Интервал в `appsettings.json` ограничен диапазоном 10–300 секунд.

Светлая, тёмная и высококонтрастная тема берутся из Windows.

## Демо-режим

В трее всегда работает настоящий провайдер Windows. Демо выключено, пока в конфиге явно не включено.

Файл `src/BatteryTray.App/appsettings.json` копируется рядом с программой:

```json
{
  "UseDemoProvider": false,
  "RefreshIntervalSeconds": 30
}
```

Чтобы посмотреть интерфейс без Bluetooth, поставьте `"UseDemoProvider": true` и перезапустите. В панели появится подпись «Демо-данные», а имена начнутся с «Демо ·». Это не настоящие устройства и не настоящий заряд. Для обычной работы верните `false`.

## Что приложение не видит

- Устройства, которые не сопряжены.
- Устройства без службы Battery Service (`0x180F`, характеристика Battery Level `0x2A19`) и без процента, который Windows уже положил в свойство батареи Bluetooth `{104EA319-6EE2-4701-BD47-8DDBF425BBE5} 2`. Так устроены многие браслеты и часть наушников: заряд виден только в приложении производителя.
- Значения вне 0–100. Они отбрасываются, а не пересчитываются в «проценты».
- Состояние зарядки, если устройство не отдаёт Battery Level Status (`0x2BED`). Тогда остаётся «Состояние неизвестно». Процент при этом может быть настоящим.
- Несколько служб батареи у одного устройства сворачиваются к наименьшему сообщённому проценту. Среднее не считается.
- Выключенное устройство часто не отвечает на свежее чтение. Кэш Windows используется только если система сама его вернула.

Классический Bluetooth и BLE одного и того же адреса показываются одной строкой. Свежее чтение GATT важнее свойства Windows.

## Как устроено

- `IBatteryProvider` — откуда брать список.
- `WindowsBluetoothBatteryProvider` — провайдер, которым пользуется трей.
- `DemoBatteryProvider` — превью интерфейса. В программу он попадает только при `UseDemoProvider: true`.

Проект `BatteryTray.Core` и тесты не зависят от Windows. Проект `BatteryTray.App` — WinForms, `net8.0-windows10.0.19041.0`.

## Проверка сборки

На Windows достаточно команд выше.

Проект также собирается не на Windows: в `BatteryTray.App.csproj` стоит `EnableWindowsTargeting`. Проверенная команда:

```bash
dotnet test
dotnet build src/BatteryTray.App/BatteryTray.App.csproj -c Release -r win-x64
```

Она даёт Windows-файл `src/BatteryTray.App/bin/Release/net8.0-windows10.0.19041.0/win-x64/BatteryTray.exe`. Запустить трей и прочитать живой Bluetooth в этой среде нельзя: здесь нет Windows и нет радио.
